Hal Penting

  • Penilaian: Meliputi Aspek Pengetahuan (P), Keterampilan (K), dan Sikap.
  • Sikap: Dinilai dengan predikat Sangat Baik, Baik, atau Cukup.
  • Kehadiran Data: Data tersimpan di browser perangkat ini. Jangan menghapus cache browser jika data belum di-backup/export.

Petunjuk Penggunaan

1. Untuk Guru

- Login menggunakan Pilihan Nama dan Password (12345).
- Masuk menu Data Siswa untuk mengunggah daftar siswa per kelas via Excel.
- Gunakan menu Input Nilai Kelas untuk menilai satu kelas sekaligus.
- Gunakan menu Kelola Tugas untuk membagikan link Google Form/materi. Guru bisa me-export hasil pengumpulan ke Excel.
- Jangan lupa Backup Data secara berkala.

2. Untuk Siswa

- Pilih Kelas dan Nama Anda di halaman Login.
- Cek tugas di tab "Tugas Kelas". Klik tombol untuk membuka Google Form.
- Jika sudah selesai mengisi Form, ketik "Selesai" lalu klik Kirim Tugas.
- Lihat grafik capaian kompetensi dan unduh rapor jika sudah lengkap.
